# Appertivo Goals

## Final Goal
Launch Appertivo as the location-based local feed people check to discover what nearby restaurants are serving right now, starting with a focused Skagit Valley launch.

## Current Status
Appertivo is a working concierge beta. The core product loop, restaurant directory, admin workflows, outreach tooling, location search, market waitlist, and six labeled launch-preview specials are in place. The next milestone is replacing preview content with restaurant-approved specials and sending useful alerts to real diners.

## Immediate Goals
- [x] Build the diner discovery feed, restaurant pages, map view, and city filtering.
- [x] Import the Skagit Valley restaurant directory and keep the product location-aware.
- [x] Build restaurant intake, admin approval, lead capture, distribution, and outreach workflows.
- [x] Add a clear Skagit Valley launch-preview experience with labeled sample specials.
- [x] Add location search with a waitlist state for markets outside Skagit Valley.
- [ ] Replace preview content with the first 10 restaurant-approved specials.
- [ ] Send the first useful early-access digest or alert to opted-in diners.
- [ ] Deploy and verify a public Skagit Valley beta with production configuration.
